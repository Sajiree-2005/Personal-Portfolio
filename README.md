# Sajiree Damle — Portfolio Website

🔗 **Live Site:** [sajiree-portflio.vercel.app](https://sajiree-portflio.vercel.app/)

Source code for my personal portfolio website — a fully self-contained, dependency-free site that showcases my projects, experience, skills, and technical interests as a **Computer Engineering student, full-stack developer, and AI/ML builder**.

Designed to feel modern, interactive, and professional, this portfolio is built to help recruiters quickly understand what I build, how I think, and the kind of problems I like solving.

---

## ✨ Highlights

* **Animated constellation background** built with the Canvas API
* **Typing-effect hero text** for a dynamic first impression
* **Scroll-reveal animations** to keep the experience engaging
* **Animated counters** for key profile metrics
* **Vertical experience timeline** for a clean career/story layout
* **Certification grid** for quick credibility scanning
* **Responsive design** that works smoothly on desktop and mobile
* **Accessibility-aware UI** with visible focus states and reduced-motion support

---

## 🛠️ Tech Stack

* **HTML5** — semantic structure and content
* **CSS3** — theming, layout, responsiveness, animations
* **JavaScript** — interactions, typing effect, scroll reveals, counters, mobile navigation
* **Canvas API** — animated background visual
* **IntersectionObserver** — efficient reveal-on-scroll effects

## 📁 Project Structure

* `index.html` — page content and structure

## 🔧 Local Setup

No build step is required.

1. Clone the repository.
2. Open `index.html` directly in a browser.

Or run it with any static server:

```bash
git clone https://github.com/Sajiree-2005/Personal-Portfolio.git
cd Personal-Portfolio
npx serve .
```

You can also deploy it for free with:

* **Netlify Drop**
* **GitHub Pages**
* **Vercel**
* Any static hosting platform

## 🎨 Customization Guide

### Change the theme

Edit the CSS variables in `css/style.css` under `:root` to adjust colours, typography, spacing, and glow effects.

### Update the hero typing phrases

Edit the `phrases` array in `js/main.js`.

### Add a profile photo

Add an image inside a new `assets/` folder and reference it in `index.html`.

### Add a resume download button

Place your PDF in the project folder and link it like this:

```html
<a href="Sajiree_Resume.pdf" download class="btn btn-ghost">Download Resume</a>
```
