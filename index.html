01 / About

Engineering with intent.

I'm a second-year Computer Engineering student at Marathwada Mitra Mandal's College of Engineering, Pune, graduating in 2028 — but I've spent most of that time building systems that don't stay inside a notebook. My flagship project, OsteoAI, is a clinical-grade osteoporosis risk-screening pipeline that fuses EfficientNetV2S with a tabular MLP, uses Focal Loss to handle class imbalance, and ships Grad-CAM explainability so a clinician can actually trust what the model is looking at.

I care about the gap between a model that performs well on paper and one that's actually deployable — which is why OsteoAI isn't just a Jupyter notebook. It's a full-stack product: FastAPI backend, React/Vite frontend, live on Vercel, built to be used.

I compete as part of Team InnoQueens, an all-women hackathon team — alongside Jidnyasa Patil, Asmi Tatawar, and Swarada Deshpande — and together we've taken OsteoAI to three wins, including 1st Runner-Up at an international hackathon hosted in Peru.

03 / Projects

Things I've built.

FLAGSHIP PROJECT

OsteoAI

AI-Based Osteoporosis Risk Detection System

A clinical-grade deep learning pipeline fusing EfficientNetV2S with a Tabular MLP (age, biological sex) to screen for osteoporosis risk from X-ray imagery. Trained on the RSNA Bone Age Dataset (~10,719 images) with Focal Loss (γ=2) to handle class imbalance, and Grad-CAM for explainability — so the model's reasoning is visible, not a black box. Deployed full-stack with a FastAPI backend and React/Vite frontend, complete with CLAHE preprocessing and heatmap overlays.
