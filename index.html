OsteoAI

AI-Based Osteoporosis Risk Detection System

A clinical-grade deep learning pipeline that fuses EfficientNetV2S with a Tabular MLP (age, biological sex) to screen osteoporosis risk from X-ray imagery. Trained on ~10,719 RSNA images with Focal Loss (γ=2) for class imbalance and Grad-CAM explainability — so clinicians can see exactly what the model is looking at, not just trust a score. Deployed full-stack: FastAPI backend, React/Vite frontend on Vercel, CLAHE preprocessing and heatmap overlays included.

Things I've learned the hard way

AI/ML

"A model that can't explain itself has no place near a diagnosis."

Building Grad-CAM into OsteoAI from day one wasn't optional — it was what made the project credible. Explainability isn't a feature, it's a responsibility.

Hackathons

"Ship the demo, not the dream."

Three wins taught me that a working, deployed product beats a perfect prototype every time. Scope aggressively, cut ruthlessly, deploy early.

Full-Stack

"The backend is easy. The gap between backend and user is where products fail."

Every project I build now starts with the frontend question: what does the person actually see and do? Then I work backwards to the model.

Volunteering

"Good tech starts with listening."

Spending time at special schools taught me that the best software is designed with the people who will use it, not just for them. Empathy before engineering.
